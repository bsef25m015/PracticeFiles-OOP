# PracticeFiles-OOP

A central repository containing practice tasks, specifications, and exercises for **CC-211: Object Oriented Programming** (BS Software Engineering, DSE, FCIT, University of the Punjab).

---

## Topics Covered

- **Classes & ADTs:** Encapsulation, access specifiers (`private`/`public`), setters, getters, and input validation.
- **Object Lifecycle:** Constructors, destructors, copy constructors, and dynamic memory allocation.
- **OOP Principles:** Composition, aggregation, operator overloading, `friend` functions, and static members.
- **Advanced OOP:** Inheritance, polymorphism, virtual functions, class templates, exception handling, and File I/O.

---

## Development Environment

- **IDE:** Microsoft Visual Studio (C++ Desktop Development workload)
- **Language Standard:** C++11 or later

### How to Run in Visual Studio:
1. Open **Visual Studio**.
2. Create a new **C++ Console App** project or open an existing solution (`.sln`).
3. Add the task `.cpp` and `.h` files to your project.
4. Press `Ctrl + F5` to run without debugging.
